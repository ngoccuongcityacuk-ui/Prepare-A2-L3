Dùng ngay: Mở file bằng trình duyệt (điện thoại, máy tính bảng hay máy tính đều được). Chọn bài → chọn Từ vựng hoặc Ngữ pháp → luyện tập.

Giao bài: Gửi file prepare-a2-level3.html cho học sinh, hoặc đưa lên Netlify Drop / GitHub Pages / Google Sites rồi gửi link.

Sửa / thêm từ: Mở file bằng Notepad hoặc VS Code, tìm const COURSE ở đầu thẻ <script>. Mỗi từ có dạng { en, vi, pos, ex } — copy một dòng rồi sửa.

Câu ví dụ & giải thích trong file do người soạn tự viết, bám theo chủ đề và điểm ngữ pháp của giáo trình Prepare Level 3 để phục vụ học tập; không sao chép nội dung sách.
